# Dramark — Brand Pack V2

These assets are cut directly from the approved Dramark brand boards.
The only intentional textual correction is the French signature:

VOTRE BIBLIOTHÈQUE DE DRAMAS

## Important repository path

Do NOT keep source assets inside `dist/`.
`dist/` is generated by Vite and can be deleted/rebuilt.

Keep these source files in:
`src/assets/brand/`

Codex may later copy the manifest/PWA icons to `public/` if the Vite PWA setup requires public URLs.
